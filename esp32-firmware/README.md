# ESP32 Classroom Attendance Node Firmware Guide

This directory contains the production-grade Arduino C++ firmware for the ESP32 classroom attendance device.

## Hardware Requirements
- Any standard ESP32 development board:
  - ESP32-WROOM-32 (NodeMCU-32S, ESP32 Dev Module)
  - ESP32-S3 or ESP32-C3
- Micro-USB or USB-C cable for flashing and power
- Onboard LED (default on GPIO 2) for status indication

---

## Arduino IDE Setup & Configuration

### 1. Install Arduino IDE
Download and install [Arduino IDE 2.x](https://www.arduino.cc/en/software).

### 2. Add ESP32 Board URL
1. Open Arduino IDE -> **File** -> **Preferences**.
2. In **Additional Board Manager URLs**, paste:
   ```
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```
3. Click **OK**.

### 3. Install ESP32 Board Package
1. Go to **Tools** -> **Board** -> **Boards Manager...**
2. Search for `esp32` by **Espressif Systems**.
3. Install version `2.0.11` or higher.

### 4. Built-in Cryptography & BLE
- No external libraries are required!
- `mbedtls` and `BLEDevice` are natively bundled with the official ESP-IDF / Arduino ESP32 core.

## Flashing Instructions

1. Open `classroom_esp32/classroom_esp32.ino` in Arduino IDE.
2. Select your board under **Tools** -> **Board** -> **ESP32 Arduino** -> **ESP32 Dev Module** (or your specific board).
3. Set the following recommended settings under **Tools**:
   - **Upload Speed**: `921600` (or `115200` if upload fails)
   - **CPU Frequency**: `240MHz (WiFi/BT)`
   - **Flash Frequency**: `80MHz`
   - **Flash Mode**: `QIO`
   - **Partition Scheme**: `Default 4MB with spiffs (1.2MB APP/1.5MB SPIFFS)`
   - **Port**: Select the COM port assigned to your ESP32 (e.g., `COM3` on Windows).
4. Review `config.h`:
   - Match `ESP32_DEVICE_ID` with the ID registered in the dashboard (e.g., `CLASSROOM_01`).
   - Match `CLASSROOM_ID` with the room (e.g., `ROOM_302`).
   - Match `SERVICE_UUID` and `DEFAULT_SECRET_KEY_HEX` with the credentials generated by the dashboard.
5. Click **Upload** (Ctrl + U).

## Serial Console & Key Provisioning

Open the Serial Monitor at **115200 baud**.
The ESP32 supports interactive commands over USB Serial:

- `GET_INFO`: Prints device ID, room, and BLE UUID.
- `SET_KEY <64_HEX_CHARS>`: Stores a new 256-bit cryptographic secret key into non-volatile flash (NVS).
  Example:
  ```
  SET_KEY E9B489601E852DDE34B76AE93D8967484B6F3E103E9946C3AE852DDE34B76AE9
  ```
- `REBOOT`: Restarts the ESP32.

## LED Status Indicator Guide

| LED State | Meaning |
| :--- | :--- |
| **Blinking (500ms cycle)** | Advertising BLE service. Ready for student phones to connect. |
| **Solid ON** | Phone connected. Challenge-response handshake in progress. |
| **Double-Blink Pulse** | Cryptographic HMAC computed and returned. Freeing connection slot. |

## High Concurrency (200 Students) Architecture

The firmware is specifically engineered to eliminate BLE connection slot bottlenecks:
1. When a student's phone connects, it writes the challenge to `CHAR_CHALLENGE_UUID`.
2. The ESP32 hardware computes the HMAC-SHA256 in `< 1ms`.
3. The response is immediately transmitted via `CHAR_RESPONSE_UUID`.
4. The ESP32 drops the connection after 100ms, and restarts advertising instantly.
5. Combined with client-side exponential backoff jitter in the mobile app, 200 students can mark attendance in 15–25 seconds.
